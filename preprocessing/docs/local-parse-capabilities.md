# 本地解析能力与限制

本地链路以材料为单位运行：预处理保存原件和清单，读取器按需读取文本、PDF 或表格，主通道按字段配置生成有来源的候选，再保存和校验结果。此说明针对本机联调，不代表正式接口或业务验收。

## 当前能力

- 本地索引接口对明确的纯扫描 PDF 可在首次读取时使用 OCR；装箱单可优先读取表格，安全数据表和探测不明确的材料沿已有分流。Markdown 未完整导出不会自动触发 OCR。
- 同一 PDF 文档范围的基础和货物扩展配置复用表格总计规则；冲突或无法确认的列仍保留未知。
- 当前正文可按明确的标签或上下文提取目的地、货源地、贸易条款、货好时间及部分联系人、包装和重量候选；邮件头元信息单独返回，不自动等同业务联系人或询盘创建时间。
- 可选正文配置分别提取货源地、提货城市、起运港或机场，以及整票净重、毛重、计费重和单件重量；来源或口径不明确时保持未知。
- 正文汇总字段会检查完整 READ 行上的“每箱／每托”等范围限定，避免将单件值作为整票总计；未明确的范围仍需人工核对。
- PDF 货物配置可提供受限商品行、单据和尺寸观察，并尝试识别多层、重复及跨页表头；货行按页面、表格、列头和单位关联来源。行、包装、单件和整票的范围分别保留，未标明的重量类型、尺寸顺序和包装归属不推断。
- 可选附件重量配置按明确指定的表格及页或工作表校验表头、货行、总计和单位；跨行、跨列、跨表或单位冲突不采纳。索引 HTTP 入口目前支持 PDF，Excel 需通过本地 Python 接口指定工作表。
- 工作台对单工作表 Excel 的商品总数量，要求数量、表头、单位及总计标记能绑定同一份 READ；`SET` 保留为套，不换算为件。正文明确为单件且尺寸可回查时，可单独展示体积估算，不能视为已确认整票体积。
- 工作台可由人工确认首询，按邮件、货票和货行组装本地询盘结果；可计算字段需绑定相同对象范围及来源。业务系统字段未连接时保留未连接状态，正式映射仍待确认。
- 本地工作台支持查看邮件、PDF、XLSX、图片和文本材料的原文、解析内容及来源；按目录和邮件回复关系初步归组，成员仍可调整，不跨邮件自动求和。业务组补提后可比较同一份 READ 的规则与 Agent 输出差异，差异数不等于准确率。
- 可从 READ 导出 Markdown 及片段来源映射；未覆盖或映射不明的内容保留限制。选择 PDF 页可补 OCR。
- 明确启用 DeepSeek 时，可对选定材料生成字段候选；待核字段可组合当前材料相邻 READ 片段，再按材料、字段范围和证据校验。可选组级补提只针对未确认的包装类型、整票体积、备注和整票毛重，验证后单列补充，不覆盖首轮或提升历史引用。默认不调用外部模型。

## 已知边界

- 文本、表格和 OCR 规则仍针对有限版式；某些转引邮件头可能导致历史内容混入当前正文，低证据或冲突结果需要复核。
- PDF 单页表格补读存在超时或进程异常的历史情况，原因尚未确认；读取失败需保留原有结果和未读范围。
- 扫描件双语总计页脚增加了同页、同次 OCR 的位置和单位校验；目前只针对有限版式，不能视为所有扫描件均已覆盖。
- 多行 PDF、扫描装箱单和 Excel 的独立货行正例仍需补充并核对；合成正反例和少量固定 READ 定向联调通过，不代表真实附件货行或全格式字段准确率已验收。
- 同组尾部读取优先级仅作为可选调度策略，现有对照未证明尾部耗时改善；混合 PDF 的图片页仍需逐页核对。
- 部分旧材料结果可能被新版来源校验拒绝；保留原快照和读取产物，按新版规则重放并重新校验。
- 比重仅在同一范围毛重和非零体积已知时计算；大货判断使用明确的计费重，不以毛重替代。正式 V1.0 映射、真实业务确认、全格式准确率和生产性能尚未验收。

真实邮件、附件、索引、运行记录和业务标识应保留在受控本地目录。
