# 本地解析工作台

在仓库 `preprocessing` 目录安装依赖后启动。PDF、图片 OCR 和 XLSX 需要另行准备已安装 Docling 的 Python 环境及本地模型缓存。

```powershell
uv sync --locked --cache-dir .uv-cache
uv run --no-sync python examples/local_web.py `
  --docling-python '<已安装 Docling 的 Python 可执行文件>' `
  --model-cache '<本地模型缓存目录>' `
  --output output/local-workbench --port 18770
```

浏览器打开 `http://127.0.0.1:18770/`，拖入或选择 EML、PDF、XLSX、PNG/JPEG、HTML 或 TXT，也可使用页面中的合成示例。服务仅监听本机；结束时按 `Ctrl+C`。

工作台分别展示邮件正文、所选附件、Markdown、解析候选和来源。导入多封邮件后，目录和邮件回复关系可用于初步归组；在“业务组核对”中检查并调整成员、参考邮件和字段来源，不把不同材料的值自动合并为业务结论。正文重量区分整票、单件和重量类型，未能归类的重量或件数线索保留原文供核对；邮件核对只比较同口径的正文整票毛重与所选附件合计。PDF 装箱单可展示已识别货行及其页、字段来源，无法确定的范围不自动补齐。PDF 页面可按需选择单页补 OCR，补读失败时核对已有读取结果和未读范围。无法读取、超时、冲突或未知的字段保留状态。邮件外链图片不会被下载。

在业务组中可单独确认首询，查看邮件头、业务系统字段及有来源的比重等计算结果，并导出本地结构化结果。未确认首询时相应字段留空；业务系统未连接时不会用邮件内容代填。具体状态和接口见[询盘本地结构化结果](../docs/inquiry-runtime-local.md)。

单工作表 Excel 的商品总数量仅在数值、数量及单位表头、合计标记均能绑定同一份读取结果时展示；`SET` 按套保留，不换算为件。正文明确为单件包装并提供尺寸时，可单独展示单件体积估算及其原文来源；估算不自动作为整票体积，`Package` 也不推断为具体包装类型。

Excel 货行体积可按原单元格格式展示；比重计算仍使用能与展示值和来源核对一致的原始精度。PDF 货行的净重在表格单元格不完整时，可依据同页匹配的位置文本补充；无法唯一对应时保留未知。

对已成功读取的正文内嵌签名图片，工作台只在当前可见正文、邮件发件地址与图片 OCR 内容能够核对一致时，补充联系人候选并保留图片读取位置；转引或隐藏的图片不参与。

本地索引 HTTP 接口另有纯扫描 PDF 的 OCR 首读分流，见[索引接口说明](../docs/local-parse-index.md)。工作台与该接口的入口和触发条件应分别核对，混合 PDF 不能仅凭整体读取成功判定每页均已覆盖。

### 可选 DeepSeek 与组级补提

默认只运行本地规则。需要外部模型时，通过当前会话的 `DEEPSEEK_API_KEY` 或本地 `private/config/deepseek.local.json` 的 `api_key` 提供已授权密钥，在启动命令末尾添加 `--extraction-agent deepseek`。密钥和配置文件不要提交到仓库。

选择“Docling · DeepSeek（业务组）”导入邮件，进入业务组核对并主动点击补提，才会发送符合条件的材料证据；候选须通过本地来源、单位及范围校验。需要对首轮仍缺的包装类型、整票体积、备注和整票毛重再补提时，同时添加 `--group-context-fallback`，每组最多追加一次受限上下文请求。采纳结果只列为补充；超时保留首轮结果，历史引用不自动升为首询。路线对照的变化数不等于准确率。

正文 READ 可生成独立货票和货行；补提按对象与缺项选择证据，并保留未发送、拒绝或采纳状态。页面保留历史引用角色，不将货票汇总值当作货行值。

工作台兼容历史 `minimax`／`minimax-group` 路线标识，但实际映射到 DeepSeek；本地 HTTP 接口也使用 `--extraction-agent deepseek`。外部模型会收到选定的证据片段，使用前应确认材料授权。

首页的经典案例是合成材料，可单独试跑。评测页只回读本机 `output/evaluation/field-review` 和 `output/evaluation/email-timing` 中格式匹配的存档汇总；无存档时显示不可用。历史耗时与固定 READ 回放耗时分别解释。

XLSX 预览有工作表和单元格数量上限，只读取已有公式缓存。PDF、图片及扫描件的提取效果取决于本机环境、模型缓存和材料本身；读取成功不代表字段或业务已验收。上传原件和结果保存在本地 `output/`，不得提交到仓库。
